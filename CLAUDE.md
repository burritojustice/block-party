# Block Party: notes for Claude

A San Francisco street-block (CNN) lookup for block party organizers. Live at https://burritojustice.github.io/block-party/ (GitHub Pages, served straight from `main`). burritojustice is the primary home; civic-joy-fund/block-party runs its own copy and is updated from here once a change checks out. Read `README.md` for the file list and data sources, `TODO.md` for what's next, and `CHANGELOG.md` for how things got this way.

## Working rules

- **Ship as a PR, always to `main`:** for any code change, make a branch, commit, push it, and open the PR against `main`, even when it builds on an unmerged PR (branch from that one and say "Includes #NN"). Never target another PR's branch: GitHub merged two stacked PRs into their parent branches after those had gone to `main`, stranding them. (`gh api repos/burritojustice/block-party/pulls -f head=<branch> -f base=main ...`; GraphQL is blocked here, so plain `gh pr create` may fail). Don't leave a branch pushed without a PR.
- **Check a PR is still open before pushing to its branch** (`gh api repos/burritojustice/block-party/pulls/<n> --jq .merged_at`). A commit pushed after the merge never reaches `main`, and editing the closed PR hides it. If it was merged, branch from `main`, cherry-pick, and open a new PR.
- **Version every change:** this applies to app and data changes; docs-only changes like this file don't need it. Bump both `<!-- build: vNN -->` near the top of `index.html` and `const _BUILD_VERSION = 'vNN'`, and add a `## vNN` entry at the top of `CHANGELOG.md`. Hovering the title shows the version, which is how John checks what's deployed.
- **Dates are YYYY-MM-DD** everywhere: data, CHANGELOG, card text, exports.
- **The creek fix applies to every map:** hide Protomaps `water_stream`, and filter names containing "Creek" or "Arroyo" out of `water_river` and waterway labels (`hideCreeks()`). John wants the same fix on all his maps, Selecter included.
- **Keep it a single file:** no build step or bundler. Libraries come from unpkg at pinned versions (MapLibre 5.6.0, maplibre-contour 0.1.0, PMTiles 4.5.0).
- **Write plainly:** UI text, README, and CHANGELOG are short and concrete. User-facing strings go in `I18N.en`; don't hard-code them in HTML builders.
- **Leave the source files:** keep raw downloads in `data/uploads/` and `reference/` as published. Scripts trim them into `data/`.
- **Data comes from sf-blocks:** the page loads `region.json`, streets, layers, boundaries, parcels and the groups list live from https://burritojustice.github.io/sf-blocks/ through `SFBlocks` (the first `<script>`, the same code as Joiner's `js/sfblocks.js`), and falls back to the copies here at the same paths. Change data in sf-blocks, then run `python3 scripts/copy_sf_blocks.py ../sf-blocks`, which updates `data/sf-blocks.json`. Aliases live only in sf-blocks' `data/aliases.json`.
- **Areas:** `AREA_SETS` (elected / special / admin: census blocks and tracts, Off·Borders·Density; density palettes `SEQ_PALETTES` / `sampleRamp`, breaks from the set's `choropleth.breaks` (`densityBreaks`), border style `ADMIN_LINE`; the census fills sit under copies of the basemap's water (`bp-water-over-*`), and parcels turn to lot lines while density shows (`parcelLinesOnly`, `applyParcelStyle`); `Areas.census()` estimates people and homes along a block) drive the Areas ▾ menu (`setupAreasMenu`, `syncAreasMenu`, `setArea`), map layers `bp-area-<k>-fill|case|line|label`, the map key (`#lg-areas`), card rows (`Areas.facts`), copy text and exports. Elected borders get paired labels from `borderPairs()` (points along shared borders, both names, rotated). Keep the three kinds apart: elected, special (not elected), administrative. `syncAreasMenu` updates buttons in place: rebuilding them mid-click makes the outside-click handler close the menu.
- **Fitting the map:** `fitSegs()` fits, then once the terrain under the blocks has loaded (polls `dem-terrain` and a height there), re-measures with `map.project` and eases out if they spill over. Without it, `#cnn=` links on hills open too close.
- **sf-blocks caching:** `SFBlocks` fetches `region.json` / `VERSION` with `cache: 'no-cache'` and other files with `?v=<version>`, so new data shows up on the next load despite Pages' 10-minute cache.
- **Cross streets toggle:** `showCross` / `updateCross()`, the checkbox in the map key; fades `bp-context*` by opacity. Off by itself when more than `CROSS_MAX` (3) streets are checked, unless turned on by hand then (`crossForced`).
- **Routes:** `state.route` (checkbox `#route-on` in `#route-wrap`, hash `route=1`, cleared by Start over). Only routes get gaps and a length (sum of `len` plus the gaps).
- **Route gaps:** `routeGaps()` (in `render()`, routes only): checked streets grouped by shared corners; the shortest hops between loose ends join the groups one by one (up to `GAP_MAX_M`, 150 m), drawn by `drawGaps()` in source `gaps` (`bp-gaps`, `bp-gaps-label`) and added to the count line. Display only: gaps aren't in exports yet.
- **Phones (`PHONE`, max-width 860 px at load):** census blocks and tracts `onDemand` (cards show `[data-census-load]` → `loadCensus()`), and the map toolbar folds to `.keep` buttons (☰ `#more-btn` only); `.map-ui.more-open` shows the rest, and picking a menu folds it. Nearby open adds `.nb-open` to `.map-wrap` (map top half, panel bottom half on phones).
- **Full screen:** `#full-btn` (in the map controls) toggles `body.bp-full` (the map wrap goes `position: fixed`), then `map.resize()`. Esc leaves.
- **Card facts:** `CardFacts.watch(segs)` (from `render()`) reads parcels and tiles (only for cards without street facts, or parcels while Land use is on) for the first 4 cards and for each card an IntersectionObserver sees within 300 px of the screen, batched; reads that come back empty are retried on the next render. Exports still read every card (`ensureAll`-style `Promise.all` in the copy path).
- **Form state:** every static `<input>` has `autocomplete="off"`, and `applyHash()` always sets the Filter boxes from the link. Browsers otherwise restore checkboxes on reload, sometimes onto the wrong ones.
- **Street facts:** `Facts` (before `Parcels`) loads sf-blocks `data/facts/streets.json` (`region.json` `facts.streets`) at boot (awaited up to 4 s before the first cards). `Facts.parcels(s)` / `trees(s)` / `biz(s)` / `census(s)` give card summaries for street blocks (not intersections or halves); `parcelFacts`, `factTileFacts` (business list as a count, `details.biz[data-biz-load]`; opening it reads the tiles), `censusRowHTML`, `Areas.text` and `Areas.fields` use them when the tiles or census blocks aren't read. `Facts.lots()` loads `lots.json` for `SelAreas.around()` (`Facts.lotIds(s)`). The rules live in sf-blocks' `build_facts.py`: change both together.
- **Map controls:** under MapLibre's zoom/compass, a `bp-ctl` group holds `#ctl-me`, `#full-btn` (SVG `ICO_FULL` / `ICO_SHRINK`) and `#ctl-3d` (3D: `setFlat(false)` + pitch 60; 2D: pitch 0 then `setFlat(true)`; label and pressed state from `sync3dButton()`). Phones: ☰ only (`#more-btn`, styled like a map control); every other toolbar button, Nearby included, is in its menu.
- **Save to:** `SaveTo.sheet('new' | 'last' | 'add')` (`GoogleDrive.signIn()` first, while the click still counts). A project is one sheet: a Routes tab (`ROUTE_COLS`, one row per save, `tab_id` / `tab_link` by gid) found by the remembered `routesTab` id then by name, plus one tab per route from `gather()` (`order` for routes, counting gaps). The last project lives in localStorage `bp-sheet-project` (`#save-sheet-last`) and `SaveTo.airtable()` (off until `CONFIG.AIRTABLE_SAVE = { table, fields: { <Airtable field>: <column> } }`; `BPAirtable.save(link, rows)` writes 10 at a time with typecast). `linkFor()` adds `route=1` for routes.
- **Filter angles:** `legBearing()` points from the corner to the block's far end; `drawAngle()` draws legs `LEG_DRAW_M` (30 m) long; `placeBeside(qpop, cnn)` anchors the hover popup in the widest gap between legs.
- **Assessor blocks for How near:** `nearMode.by === 'ablk'` with `ring` 1 or 2. `Areas.touching(k, it)` (a street: 18 m to each side at 15/50/85%; a corner: 16 directions at 26 and 36 m; a point: the area it's in, else around it); ring 2 adds `Areas.neighbors('ablk', n, ABLK_ACROSS_M)` (35 m, across the street). `Drops.ablkOf` / `inAblk` (in the block, or within 10 m of it) serve cards (`hitsFor`), the extent (`extentOf`) and Nearby (`matchOne`; places on the network use `targetOf`, others their point).
- **Nearby picks:** `NearbyView.pick(ll, pan)` rings a match (`nb-pin`, `bp-nb-pin`) and marks rows `.is-picked` (kept on redraw via `isPinned`); a click on `bp-nb-match` calls `revealMatch(sid, lkey, ll)` (opens the place and list in the table). Match features carry the exact point as `ll` (rendered coordinates are rounded). `nbBizCats` filters Nearby's businesses by `cat` (chips under Businesses).
- **Business records:** `sinceText()` / `sinceBadge()` put "Here since … · N years" near the top of `bizOne` and on card list lines. In Address / Places, `Places.bizRec(b, pin)` finds the business in the tiles for the full record (`.pc-rec`), and a click on `bp-place-pin` opens it.
- **◎ (`#ctl-me`):** `NearbyView.locateMe()`; location uses `enableHighAccuracy: PHONE`, so computers answer from Wi-Fi.
- **Route gaps in exports:** `withGaps(segs, recs)` puts `gapRecord(g)` rows (kind `gap`, corners, length, WKT line) after the street each gap leaves from; used by `copyRecords` and by `Downloads.rows('blocks')` for routes (which then keeps route order).
- **Street View:** `streetViewUrl(o)` (mid-block, heading along the street; corners without a heading): `street_view` in `record()`, `STREET_COLS`, a link cell in the table, and the card's length line.
- **Import panel:** `#import-panel` / `#import-side` in the sidebar, filled by `renderMenu()` from `importControls()` (shared with the Layers fold) plus the file list (`data-imp-x` → `askRemove`); `#import-n` counts files.
- **Busy pill:** `Busy.track(kind, key, promise)` (parcels, tiles, areas) feeds `#busy` over the map while cards read their details.
- **Loading:** `#map-loading` (spinner + `#map-loading-text`) stays until the first `idle` after `applyHash()` when the link has CNNs (at most 6 s).
- **Apply button:** `CONFIG.APPLY` (`show`, `url`, `params`). Off on this build; civic-joy-fund's copy turns it on. See the README.
- **Drawing order:** `LAYER_ORDER` / `orderLayers()` (called by `arrangeLayers()` whenever layers are added or the basemap changes) moves every layer above the basemap's ground into groups: shading, edges, streets (Muni band, street lines, bike lanes, Slow Streets), points, selection, 3D, labels (all symbol layers, the basemap's included). A new `bp-` layer must go in a group, or it's drawn with the streets and logged. The Layers menu follows `LAYER_SECTIONS`.
- **Hover order:** your files' points and lines > corners > points (`HOVER.points`: POIs, trees, businesses, your files) > buildings > parcels and city land > street blocks; each handler checks `onPoi` / `onBuilding` / `onArea` and gives way. The shared popup has an owner (`popOwner`): only the handler that opened it closes it. Popups take no pointer events (CSS), or one opening under the pointer fires the map's mouseout.
- **Which areas a block is in:** `Areas.of()` samples 25/50/75% along the block, on the centerline and `SIDE_M` (12 m) to each side, so border streets get both districts (most-covered first).
- **Card lists on the map:** opening a card's trees or businesses fold calls `Tiles.highlight()` (source `card-hl`, layers `bp-card-hl*`); a click on a tree or business opens its record (`treeRecord` / `bizRecord`, popup class `bp-rec`, the one popup that takes pointer events).
- **Basemap checkboxes:** `basemapHide` (localStorage `bp-basemap-hide`: pois, buildings, addresses, the last being the basemap's `buildings` symbols) and `applyBasemap()`, which also hides places and colored land under density. Map style is `basemapFlavor` (`bp-flavor`, `FLAVORS`): the first load uses that flavor's style URL; `setFlavor()` fetches another flavor and copies its paint and layout (not visibility) onto the same layer ids and the `bp-water-over-*` copies, plus its sprite. 3D on/off is `flatMap` (`bp-flat`): `applyTerrain()` sets terrain and max pitch, `sync3dButton()` turns the 3D button into Contours.
- **Import:** the `<details data-import>` fold in `renderMenu` holds the file picker, link form, Google Drive (`fromDrive()`, an inlined copy of sf-blocks' `matcher/google-drive.js`, config from sf-blocks `matcher/google.json`) and the Airtable placeholder.
- **Airtable:** `BPAirtable` (just before `Drops`; same rules as Joiner's `js/airtable.js`): token in sessionStorage `bp-airtable-token`, never in the hash; `parseLink` takes a link or bare path; `load()` skips contact fields (`SKIP_TYPES`, `SKIP_NAMES`), resolves linked records (WKT → `geometry` via `Drops.combineWKT`, CNNs → `cnns`); dialog `#at-dlg` (token, optional link, base → table / view list). Rows go in with `Drops.addRows(name, rows, 'airtable:<path>')`, so the hash keeps `url=airtable:…` and `addURL` hands it to `BPAirtable.fromHash`. Tests mock `api.airtable.com` with `page.route` (IDs are 17 characters: `app` + 14).
- **Address / Places:** `Places` (before `SelAreas`): in `state.mode === 'addr'` the street box's `getOptions` calls `Places.options(q, streetItems)`, which mixes addresses (parsed `<number> <street>`, from sf-blocks `data/search/addresses/<k>.json` shards via `index.json` `streets`), lots, streets, NAICS codes and titles, businesses, landmarks, layer places (`fetchLayer`) and your files' rows, with `sepBefore` headings; values are `place:<n>` (`Places.pick`). Data loads lazily (`index()`, `business()`, `shard()`), then `Places.onLoad` → `streetBox.refresh()`. `Places.show(p)` draws source `place` (`bp-place-lot-fill`, `bp-place-lot`, `bp-place-pin*`), puts the street in the list with `setResults`, and fills `#place-card` (moved into `.lookup`). Lots: `lotParts()` (4 digits + letter, 3 digits + letter). NAICS / all matches go in as files with `Drops.addRows`. **Pick the lot** → `SelAreas.addLot(lot, r)`.
- **File sources and locations:** each file has `src` (file, drive, sheet, socrata, url, airtable, search; label `src_<src>`), `_raw` (CSV text or row objects) for `relocate(id, loc)` (Format → Location from: `locs` / `loc`, 'latlon' or a geometry column). `fromRows(head, rows, pref)` finds geometry columns by `GEO` / `GEO_ANY` and prefers a non-point one (outline first) over lat / lon (`cols.geoFirst`). `wkt()` reads GEOMETRYCOLLECTION. Airtable files carry `at` ({link, skipped, include}); Format → Fields left out reloads through `BPAirtable.reload(fid, at, include)`; the hash keeps `url=airtable:<path>|<field>|…`. `Drops.syncExtent()` (end of `render()`) drops a card's How near outline when its street is unchecked or gone.
- **Your files:** `Drops` reads a dropped or picked CSV/GeoJSON (lat/lon, WKT, "(lat, lon)" or CNN columns), or a link (`addURL`: Google Sheets, Socrata, any CORS-readable file; kept in the hash as `url=`), into layers `bp-drop-<n>-fill|line|pt|label`, the "Your files" rows in Layers (`#drop-rows`), map key rows, and card rows (`Drops.facts`). Cards list rows by `nearMode` (localStorage `bp-near`): `blocks` (`blocksOut`: this block or N steps along `segsAtNode`; CNN match, else within `DROP_ON_M`), `area` (`Areas.areasAt`), or `radius`. `Drops.areaNames(k)` feeds `Areas.updateShade`. Dropped files live in the tab only. Swatches are `DROP_SWATCHES` (ROYGBIV, aqua, magenta, black, white); new files take `DROP_COLORS` in order. Each file has a `look` (Format: `by`, `size`, `sizeBy`, `style`, `labels`, `labelZoom`; `classes()`, `data()` writes `_c` / `_s` / `_lab`, `restyle()`), and its points and lines sit in the `files` drawing group above the selection, so they beat corners. `FeatCards` (`Drops.cards`): a picked row goes on the card of the block or intersection it's at (`targets()`: its CNNs, split into `_segs` / `_nodes`; else an intersection within 15 m; else the nearest block within 40 m), shown at the top by `Drops.picked(s)`, with `onCards` pruned in `render()`. Rows with no target (polygons, far from streets) get a stand-in card in `#feat-list` (inside `#results`). `detailsFold()` folds Matcher (`MATCH_COLS`) and location columns away. A file's rows on a card get Copy list / CSV (`data-copy-drop` / `data-csv-drop` = `<cnn>:<fileId>`, rows from `Drops.listRows(s, fid)`). **Reset view** (`#layers-reset`) restores `OVERLAY_DEFAULT`, `AREA_DEFAULT`, chips, `basemapHide`, `flatMap` and `nearMode`.
- **Neighborhoods on the map:** `AREA_SETS` kind `hood` (`nh_<set>`), one at a time: the card's `hoodSet`, mode `areaMode.hood`. Loaded only when shown (`Areas.need`), not by `Areas.ensure`.
- **Intersection cards:** `IntLegs.of(i)` cuts each street at the corner halfway (stand-in blocks `<cnn>h<corner>`, `halfOf`); `Areas.census`, `Parcels.fetch` and `Tiles.fetch` add the halves up for an intersection, and `Areas.corners` uses the census blocks touching the corner.
- **Map key categories:** `LgKey.pickCat` (`CATS`: bizCats, treeGenera, landCats): the first click in a key shows only that category, the same one again shows all but it, others toggle.
- **Map key checkboxes:** `LgKey` adds a `.lg-onoff` box to overlay rows (`lg-lyr-<k>`), area rows (`data-lg-area`) and file rows (`data-lg-drop`); rows turned off there stay listed (`overlaysOff`, `areasOff`, `dropsOff`). Category rows carry `data-hl` (their color); hovering one sets the layer's opacity to a `case` on `['to-string', <its color expression>]`, restored on mouseout.
- **Downloads:** `Downloads.rows(what)` (blocks, businesses, parcels, cblocks) from `exportSegs()`, `Tiles.peek`, `Parcels.peek` (lots keep `rings` and `addr`) and `Areas.census` + `Areas.geom`; de-duplicated with a `cnns` column. `addCrossStreets()` adds the first block of each crossing street.
- **Selection panel:** `SelAreas` (`#sel-panel`): `around()` adds streets whose lots are mostly on the assessor blocks (`mapblklot` minus the lot's 3 digits) the checked streets face; `save()` writes a Feature (name, cnns, streets, lots, saved) with an outline from turf (loaded lazily from unpkg, 7.1.0): 15 m street buffers unioned with the lots, closed by ±3 m; `open()` / `pick()` edit one area of a FeatureCollection and save the whole file back. Hovering key categories uses `toOpacity()`, which rewrites the layer's color expression into opacities. `history` / `remember()` / `undo()` keep the selection before each grow step. Picking areas: `pickMode(k)` (ablk, cblk, ctract), `onMapClick` toggles `picks`, drawn in `bp-pick-fill|line`; street, corner and file clicks check `SelAreas.picking()` and give way. `streetsAround()` adds eligible streets with a point 14 m to either side (25/50/75% along) inside a pick. Saved areas carry `area_set` / `areas`.
- **Table:** `Table` (`#table-btn`, `#tbl-drawer` at the bottom of `.map-wrap`; `.tbl-open` moves `#map` and the key up by `--tbl-h`, saved as `bp-table-h`): rows from `record()` for streets (`STREET_COLS`, or all but `wkt`/`link`) or a file's properties; `Table.refresh()` runs at the end of `render()` and in Drops' `renderMenu`. File rows use `Drops.cards.spot` / `has` / `toggle`.
- **Business dots:** `bizExprs()` gives count, color and filter: from the tiles' `shown_<cat>` / `n_<cat>` (summed over `bizCats`) when present, else `n` / `shown` and `cat`.
- **Reading files:** `headerRow()` finds the column names in the first 30 rows; with no readable coordinates or CNNs, `textCorners()` places rows at intersections (`INT_SPLIT` in one column, or `ST_COL` + `X_COL`, via `Logic.resolveStreet` / `intersectionOf`; `how: 'corner'`). Drive sheets with several tabs go through `pickTabs()` (a `<dialog>`).
- **File shapes:** new files take `SHAPE_ORDER` in turn (stars first); the card highlight draws shapes in `bp-feat-hl-sym`. `look.shape` (`DROP_SHAPES`); non-circle points draw in `bp-drop-<n>-sym` with SDF icons `bp-shape-<k>` made by `shapeImage()` (`SHAPE_PATHS`, re-added on `styleimagemissing`); the circle layer's filter empties instead.
- **Pick outlines:** `SelAreas.pickOutline(how)`: `blocks` (union), `filled` (±18 m), `centerline` (`turf.polygonize` of eligible street centerlines near the picks; each pick takes the face holding its `pointOnFeature`, unless the face is over 3× the picks in it plus 20,000 m², then the pick +10 m). Faces whose own middle falls in a pick count too (streets through blocks). Previewed in `bp-pick-outline`. `alongStreets()` samples 10–90% along each checked street, 10/16/24 m to each side, keeping areas hit at least twice. Pick-mode hover: `onMapMove` → `hoverArea(n)` (`bp-pick-hover`, chip `.is-hl`, table `tr[data-pick-row]`). `reset()` runs from `startOver` / `clearSelections`; `active()` keeps `#results` shown. `clicking` is separate from `pickSet` / `picks`, so Off keeps the picks. Block cards: `SelAreas.cardsHTML()` (`li.seg.blk[data-blk]`, after the street cards in `render()`), `cardClick()` (intercepted first in the list's click handler), `streetsAroundOf(names)`; assessor facts from `Parcels.fetchBlock(n, geom)` (every lot whose `mapblklot` minus 3 digits is the block, cached as `ablk:<n>`) through `parcelFacts(s, true)`. No mode: `picking()` is always false; `onMapClick` / `onMapMove` skip when `onOther(e)` (streets, corners, points, files). Hash `pick=<set>:<a;b>` (`pickHash`, `restore`).
- **Words:** a CNN segment is a street, `block` only an assessor / census block or tract. Titles: `linkedBlocks` ("Your selection"), `blocksTouching`; the count line comes from `kindLine()` in `render()` plus `SelAreas.countText()`. `SHOW_LEGS = false` keeps the blocks leading into an intersection out of the list.
- **Copy / Save:** `#save-panel` (folded). `copyRecords()` (Copy CSV / JSON) and `Downloads.rows([... 'picked'])` add `SelAreas.exportRows()`; downloads sort by `kind` (`ORDER`). `linkFor()` adds `pick=`.
- **Parcels as picks:** `pickSet === 'parcel'`; SelAreas goes through `geomOf`, `namesAt`, `setTitle`, `setId`, `propsOf`, `needSet`, `showSet`; lots live in `lotStore` (from `Parcels.lotAt(lng, lat)` on read tiles, `Parcels.fetch(seg).byLot` for along-the-streets, `Parcels.findLot(lot, blockGeom)` for links). Block and parcel counts: `statsOf(n)` (Tiles merged from the streets around, businesses inside the outline, stored with `Tiles.put('blk:<set>:<n>')`; people and homes from `Areas.inBox('cblk')` × overlap share), shown by `countsHTML()`.
- **Border styles:** `BORDER_GROUPS` / `BORDER_STYLE_KEYS` (`elWidth|Color|Dash|Labels`, `sp…`, `hd…`, `adminDash`) in `areaMode`, saved as `bp-borders`; applied in `Areas.apply()`, the style row `styleBox()` in `setupAreasMenu()`. Hillshade is overlay `hillshade` (`bp-hillshade` visibility).
- **Card clicks and hover:** hovering (`hoverSegFromCard`) highlights only; a click on the card body (not the checkbox) calls `goToCard(s)` (fit + `lastCardCnn`); table rows call `goToCard` + `jumpToCard`.
- **Nearby section:** `nearbyHTML(s)` (businesses via `tileFacts(s, 'biz')`, `Drops.facts`, `groupsFacts`) under `.near-head` with `Drops.nearPicker()` (`select[data-near-card]` → `Drops.setNearFrom`). `Drops.showExtent(s)` draws `extentOf(s)` (blocks out, the area, or a radius hull) in `bp-near-fill|line`. Highlighted businesses (`hlBiz`, `Tiles.hlBiz(i)`) get `bp-card-hl-label`, hover and click.
- **◎ Nearby (`NearbyView`; the older `Nearby` is the cards' "Next to" row):** panel `#nb-panel` (bottom sheet under 860 px). Places are `{ id, name, ll, m (meters), polys, props, cnn | node | segs | nodes }` from `placesOf(key)` (files via `Drops.items`, `streets`, `me`, overlay GeoJSON via `fetchLayer`) or `tilePlaces()` (businesses, trees via `Tiles.inBox`). `matchOne()` follows `Drops.nearMode`: blocks (`targetOf()` then `Drops.blocksOut`, within `ON_M` 35 m or by CNN), area (`Drops.areaKey()`), or radius (`dist()`); neighborhood groups come from `Groups.of()` at the place. Results go to the table as source `nearby` (`NearbyView.tableRows` / `subRowsHTML`, rows open via `opened`) and the map (`bp-nb-start|match|me`). Exports: `csvRows()` (one row per match), JSON, GeoJSON. Near me: `locate()` with `watchPosition`, re-running after 30 m. Districts (`AREA_LISTS`: cbd, cult) match by the area a place is in, with contacts from sf-blocks `reference/cultural-districts/contacts.csv`. Opened rows show per-list folds (`openGroups`, `toggleGroup`) and per-place exports (`exportAs(kind, id)`); the table head's `#tbl-nb` holds How near and exports. `showArea(pl)` draws the how-near extent through `Drops.showExtent(item, true)`. "Same or touching neighborhood" is `nearMode.adj` (`adj:hood`), via `Areas.neighbors(k, name)` (borders within 8 m) and `Drops.withAdj`.
- **Clearing:** `clearSelections()` and `startOver()` both call `clearPicked()` (`Drops.cards.clear()`, `NearbyView.clear(true)`, `Drops.showExtent(null)`); `startOver` also turns off Focus and Filter (`clearQuiet()`). `resetMap()` (buttons `#reset-map` in Options and `#layers-reset` in Layers) resets overlays, areas, border styles (and removes `bp-borders`), basemap, 3D, Filter and How near. Removing a file goes through `askRemove(id)` (`#rm-dlg`), then `remove()` ends Focus on it and calls `NearbyView.dropFile(id)`.
- **Focus:** `Focus` (before `HOVER`): `Focus.gate(map)` wraps `map.on` so every layer-tied click / hover handler runs only when `Focus.allows(layerId)`; `hoverHit` skips paused layers too. Kinds: streets, ints, biz, trees, places, lots (parcels / city land popup; turns Parcels on via `autoLots`), or `f<id>` (a file, through `Drops.focus`). Menu `#focus-pop` from `#focus-btn`, `#focus-off` ✕, Esc. Map-level handlers check `Focus.kind` themselves (area popup, SelAreas, Drops' `live_`).
- **Filter intersections:** `Logic.nodeShapes()` (legs that pass `legOk`: built, public, drivable, not freeways or ramps; bearing to 25 m along; `corner` = smallest angle between two different streets' legs, with `bs`, `names`, `pair` for drawing; `off` kept for reference) and `Logic.cornerMatches(on, angle)` (corner < angle); `tee` / `skew` chips in `#quiet-panel`, slider `#skew-angle` (`bp-corner`, corners sharper than), points in source `quiet-int`, layer `bp-quiet-int`; hovering one calls `drawAngle(cnn)` (source `quiet-angle`, layers `bp-quiet-angle*`). Headless tests: terrain makes drawing very slow; `setFlat(true)` before screenshots.
- **Nearby hover:** rows and matches carry `data-nb-ll`; `NearbyView.hover(ll)` rings it (`nb-hover`, `bp-nb-hover`). The table's Nearby header cells come from `NearbyView.headHTML(c)` (table class `tbl-nbmode`).
- **Focus and next steps:** `Drops.focus(fid)` hides `bp-all-hit` / `bp-corners-hit`, fades `FADE` layers, limits `pointIds` / `fillIds` to that file, shows a toast and the `#focus-wrap` button in map-ui (click or Esc ends it). Selecting parcels turns on Parcels and remembers it (`autoParcels`) so leaving parcels turns it off. A second click on Map opens `#flavor-pop`. `nextSteps(f)` fills `#next-toast` after a file loads.
- **3D buildings:** `Tiles.tilt()` on every pitch change: the extrusion layer shows while tilted, at `BLDG_STEPS` heights up to `BLDG_FULL_PITCH`.
- **Buttons:** black when on or open, white when off; yellow only for what's picked on the map.
- **Basemap key:** Protomaps `071e272e8d5e13b7` (allowed origin burritojustice.github.io; localhost works with any key). `SFBlocks.basemapKey()` picks another origin's key from `region.json`.

## How `index.html` is laid out

Top to bottom (search for these names):

- **`CONFIG`, `HOOD_SETS`, `I18N`**: settings, the neighborhood sets shown on cards, and all UI strings (`t(key)`). The set shown on closed cards is `hoodSet` (`hoodsHTML`), saved in localStorage as `bp-hoodset`.
- **`Logic`**: loads `streets.json` and handles everything that isn't the map:
  - street name normalizing and search
  - cross streets in order (Dijkstra along the street)
  - between / at address / intersection lookups
  - dead ends (an end within 1.5 m of another drivable street counts as open, e.g. Comerford)
  - quiet-street filters (`QUIET_SHOW` / `QUIET_NARROW`)
- **`Elev`**: Terrarium DEM sampling, which drives the slope and elevation profile on cards and slope on hover.
- **Form and results**: `setupForm`, `select*`, and `render`. Cards are built by `cardHTML` (blocks) and `intCardHTML` (intersections). `cardText` and `record` / `toCSV` handle copy and export. The URL hash (`#cnn=...`) round-trips through `writeHash` / `applyHash`.
- **Map**: `initMap`, `hideCreeks`, `addMapLayers`, label modes (flat labels above `LABEL_3D_PITCH`), contours, basemap / satellite.
- **Overlays**: `OVERLAYS` / `OVERLAY_DEFAULT` / `overlayMode`, then `applyOverlay(k)` / `updateOverlays()`, with data loaded lazily by `loadOverlay` / `fetchLayer`.
  - Layers are shown and hidden by **visibility, not `setLayerZoomRange`**, which was unreliable with terrain on.
  - City-owned land has category chips (`setLandCats`).
- **`Transit`**: Muni and bike lanes on each block.
  - Muni routes match a block when they run along it: within 15 m at 25/50/75% along the block, and heading within 30° of it.
  - Bike lanes and Slow Streets join by CNN.
- **`Nearby`**: the "Next to" row. City Lands parcels within 20 m (at least 2 samples, 10% trimmed off each end), plus point layers within 35 m.
- **`Parcels`**: land use and zoning on cards, decoded from the zoom-15 pmtiles with a small built-in `decodeMVT`.
  - A lot counts within 14 m of the middle 70% of the block, or 25 m if its address is on the same street. Lots are de-duplicated by `mapblklot`.
  - The zoning palette is SF Planning's (`ZONING`, from their MapServer layer 3).
  - The white outlines on counted lots (`updateAdjLots`) show only while Parcels is on.
- **`Tiles`**: map layers from sf-blocks' `data/tiles/index.json` (`region.json` `tiles`): `TILE_SETS` maps Block Party keys (trees, businesses, curbs, buildings) to sf-blocks ids; `Tiles.register()` adds them to `OVERLAYS` (with `zooms`: close / always / label) before the map layers, `Tiles.addLayers()` adds `tl-<k>` sources and `bp-lyr-<k>` layers, `Tiles.filter()` applies the genus and business chips and `bizAll` ("Show all registrations"). Cards read the same tiles at the detail zoom (`Tiles.fetch` / `peek`): trees by CNN, businesses by street name and address range. `decodeMVT` keeps point features (one-vertex rings).
- **Contact data:** city-published registries (businesses, SF Planning's groups) show on cards and in Copy list and exports, owner names and mailing addresses included; never as map labels.
- **`Groups`**: SF Planning neighborhood groups for the block's Planning neighborhood (`hood_planning`), with expand and "Copy list".

## Data

- **`data/streets.json`**: compact format with `seg_fields` / `node_fields` and a shared `strings` table. Geometry is delta-encoded ints (`Logic.decodeGeom`). Optional fields are looked up by name: `slope_avg` / `slope_max`, and `hood_analysis|sffind|planning|realtor|wof` ("; "-joined when a block crosses a boundary). Rebuild with `python3 scripts/build_data.py --slopes --areas`. `--slopes` needs the Terrarium S3 tiles, which are blocked from Claude's sandbox; see Gotchas.
- **Where the neighborhood fields come from:**
  - The streets CSV's `nhood` is DPW's realtor-style neighborhood, shown as "Streets file (DPW)".
  - `analysis_neighborhood` also comes from the CSV.
  - The `hood_*` fields are point-in-polygon tests at 25/50/75% along the block, using `data/boundaries/`.
- **`data/layers/*.geojson`**: trimmed overlays. Rebuild with `python3 scripts/build_layers.py` (`--download` refreshes from DataSF; the Socrata ids are in `SOURCES`). Schools has hand-added columns and is never re-downloaded.
- **`data/Land_Use_with_Active_Parcel_Information.pmtiles`**: parcels (2023 land use plus zoning), built by John with tippecanoe. A slimmer rebuild is on the TODO.
- **`reference/neighborhood-groups/neighborhood_groups.json`**: from `reference/neighborhood-groups/` via `scripts/build_neighborhood_groups.py`. It keeps only organization, name, email and preference; addresses and phones stay in the reference copy.

## Gotchas we've hit

- **Mixing filter syntax:** MapLibre won't mix legacy filters (`["==", "kind", ...]`) with expressions. `hideCreeks` converts the style's legacy filters first, and uses `coalesce` for a missing `name`.
- **`querySourceFeatures` with terrain:** it returns nothing while terrain is on. Use `queryRenderedFeatures` (parcel labels do).
- **Layer ordering:** inserting a layer `before` one that doesn't exist yet fails silently. Insert before the `below` anchor.
- **Class names:** `.seg` is taken by cards; the layer-menu segmented control is `.lseg`.
- **Network from Claude's sandbox:** DataSF (`data.sf.gov`) and the Terrarium S3 bucket are blocked. Ask John for exports, or post-process an existing `streets.json`. A GitHub Action could do scheduled refreshes; it's on the TODO. WebFetch reaches some ArcGIS REST endpoints (e.g. sfplanninggis.org).
- **Shallow clones:** the fetch refspec only covers `main`. After pushing a branch, run `git config --add remote.origin.fetch '+refs/heads/*:refs/remotes/origin/*'` and `git branch -u origin/<branch>`, or the stop hook reports it as unpushed.
