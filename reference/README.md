# Reference

Lists and documents Block Party uses that aren't maps. Each folder keeps the copy as published, with the date it was published or downloaded in the file name, plus a README saying where it came from and how it's used.

| Folder | What | Used by |
|---|---|---|
| `neighborhood-groups/` | SF Planning's neighborhood group notification list | `scripts/build_neighborhood_groups.py` → `neighborhood-groups/neighborhood_groups.json` → the "Neighborhood groups" row on cards |
